# Development changes

This is a feature summary, not a changelog for a released ZIP.

## Handheld controls and interface

- Added SHIELD Console, controller navigation, cover/icon reset, favourites and launcher intro settings.
- Added controller mappings and profiles while preserving NVIDIA long-press power behaviour.
- Added SHIELD accessory-management work and an optional Quick Panel with per-app exclusions.
- Added fan choices and automatic selected-app cooling.
- Added HDMI console-mode and audio reliability/latency work.

## Graphics settings

- Renamed the user-facing graphics entry to RothGL.
- Added the simpler About, Google Play ES3 games, Games and FPS counter layout.
- Added a simple per-game switch with older compatibility options behind Advanced.
- Kept normal global graphics reporting at ES2 and unvalidated GPU boost disabled.

The current private full-ROM ZIP predates the latest Settings layout. Feature development and individual device confirmations do not mean every change has passed a combined fresh-install release test.
